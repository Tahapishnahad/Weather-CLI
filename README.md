# 🌦️ Weather CLI

A command-line weather application built with Python that retrieves weather information for a specified location and presents it directly in the terminal.

## ✨ Features

- 🌍 Get weather information for a location.
- 🌐 Retrieve data through a weather API.
- 📊 Process API responses and display weather information in a readable format.
- 🐍 Built with Python as a hands-on programming project.

## 🛠️ Built With

- **Python**
- **HTTP requests and JSON** for working with API data

## 🚀 Getting Started

### Prerequisites

- Python installed on your system.
- An internet connection.
- Any API credentials required by the weather service used in this project.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Tahapishnahad/Weather-CLI
   ```

2. Install the project's dependencies using its dependency file:

   ```bash
   pip install -r requirements.txt
   ```

### Usage

Run the project's main Python script:

```bash
python Weather.py
```
